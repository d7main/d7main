## About

I'm a Mechatronics student from **Ukraine**, currently studying in the **Czech Republic**.

My main focus is on **embedded systems, electronics, IoT, and hardware-software integration**. I enjoy taking projects from an initial concept through firmware development and PCB design to a functional prototype.

### Areas of focus

* **Embedded Systems** — ESP32, ESP-IDF, FreeRTOS, low-level firmware
* **Electronics** — schematic design, component selection, power management, debugging
* **PCB Design** — multi-layer PCB design, routing, signal integrity, manufacturing preparation
* **IoT** — connected devices, sensors, wireless communication, low-power systems
* **Software** — C, C++, C# and .NET desktop applications
* **Engineering** — CAD, prototyping, testing and hardware/software integration

Currently expanding my knowledge in **advanced ESP-IDF, RTOS architecture, embedded Linux, PCB design and engineering CAD/CAE tools**.
